# JS/TS Drills

Small daily exercises for building JavaScript and TypeScript muscle memory.

## Purpose

Practice syntax and primitives (arrays, objects, async) so they become automatic,
freeing up mental space for real problems in the main Expense Splitter project.

## Structure

- `src/01-basics/` — variables, functions, template literals, spread
- `src/02-arrays/` — map, filter, reduce, find, forEach
- `src/03-objects/` — objects, arrays of objects, destructuring, JSON
- `src/04-async/` — promises, async/await, try/catch
- `src/05-types/` — unions, interfaces, generics

## How to run a drill

    npm run dev src/02-arrays/01-map.ts
